# TechZone — дипломeн проект

Демонстрационен интерфейс на онлайн магазин за електроника, изграден с HTML, CSS и JavaScript.

## Стартиране
1. Разархивирайте папката `TechZone`.
2. Отворете `index.html` в браузър. За по-удобна работа използвайте Visual Studio Code с разширението Live Server.
3. Продуктите и количката са демонстрационни; количката се запазва локално в браузъра.

## Функции в първата версия
- Адаптивен тъмен дизайн
- Каталог с примерни продукти
- Търсене по име, категория и описание
- Филтриране по категория
- Сортиране по цена и име
- Добавяне и премахване на продукти от количката
- Запазване на количката чрез localStorage

## Важно за дипломния проект
Тази версия е фронтенд прототип. Реална регистрация, вход, база данни и защитен администраторски панел изискват сървърна част и база данни. Не съхранявайте пароли или тайни ключове в JavaScript, изпращан към браузъра.
